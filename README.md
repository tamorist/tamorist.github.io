# ClimateWatchMan

Live site: <https://tamorist.github.io/>

The entry page for a small collection of sourced sites on the climate crisis (Japanese / English):

- [Before the Tipping Point / 臨界点の手前で](https://tamorist.github.io/tipping-point/) — the whole picture: carbon budget, tipping points, cascades
- [The Slow War / 静かな戦争](https://tamorist.github.io/slow-war/) — future deaths locked in by today’s emissions
- [83 Billion Reasons / 830億の理由](https://tamorist.github.io/83-billion/) — eating less meat, for animals, the planet and health

To add a new site, add one entry to the `SITES` array in `index.html`.
